📘 如何获取微博正文 ID 或链接

📱 方法一：手机端（推荐）

1. 打开微博 App 或手机浏览器访问 m.weibo.cn。

2. 找到您想要分析的微博正文，点击右上角的 「···」 或分享按钮。

3. 选择 「复制链接」。

4. 粘贴到输入框中即可，系统会自动识别。

示例链接：
https://m.weibo.cn/detail/4876543210987654

✅ 链接中包含的 4876543210987654 就是微博 ID（MID）。

💻 方法二：电脑网页端

1. 用浏览器打开微博官网 weibo.com 并登录。

2. 点击进入某条微博的发布时间。

3. 此时浏览器地址栏的网址就是微博链接，例如：

https://weibo.com/1234567890/AbCdEfGhI

4. 直接复制整段网址，粘贴到分析页面的输入框即可。

💡 网页版链接中的 AbCdEfGhI 是短 ID，系统会自动转换为数字 MID，无需手动处理。

🔢 方法三：直接使用数字 ID

如果您知道微博的数字 ID（通常为 16 位左右纯数字），可以直接输入。

例如：4876543210987654

该 ID 可以从微博正文页的网页源代码中查找，或通过第三方工具获取。

✨ 小贴士
• 任何包含微博正文的链接（无论是 m.weibo.cn 还是 weibo.com）均可直接粘贴，系统会自动提取 ID。
• 若不确定，直接将复制的链接完整粘贴即可，无需手动提取数字。
